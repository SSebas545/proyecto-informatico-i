# Proyecto Informático I — Los Patismos

Sistema de gestión de librería. La etapa actual es la **2**: wireframes
y casos de uso. La etapa 3 será el desarrollo del sistema.

## Stack

HTML5, CSS3, JavaScript, Node.js y MySQL.

## Dónde está cada cosa

| qué | dónde |
|---|---|
| wireframes | `wireframes/` |
| casos de uso | `casos_de_uso/` |
| documentación | `documentacion/` |
| recursos | `assets/` |
| notas de Obsidian | `~/.config/obsidian-notes/proyectos/` |

## Notas de Obsidian

tienen el detalle de cada uno:

- `~/.config/obsidian-notes/proyectos/Proyecto_Informatico_I_Casos_de_Uso.md`
