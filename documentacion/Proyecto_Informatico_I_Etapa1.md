### Ficha del Cliente y Problema

**Cliente:** Propietario de una librería tradicional (venta y préstamo de libros).

**Situación actual:** Es un negocio físico que tiene un catálogo extenso, pero cuya administración se quedó en el tiempo. Todas las gestiones se realizan de manera manual, dependiendo exclusivamente de la memoria del dueño y de registros en cuadernos de papel.

**Problema:** Actualmente, cuando un cliente ingresa al local para consultar el stock de un libro específico o pedir recomendaciones de un género en particular (terror, drama, acción, etc.), el proceso es lento y propenso a errores. El dueño pierde mucho tiempo buscando físicamente en las estanterías o revisando planillas desactualizadas. Muchas veces se le confirma a un cliente que un libro está disponible, pero luego se descubre que en realidad fue prestado, se vendió y no se anotó, o su estado físico está demasiado deteriorado para entregarlo. Esta falta de control genera demoras, pérdidas de ventas y una mala experiencia para los usuarios, además de imposibilitar la recomendación ágil de títulos nuevos.

**Solución:** Se busca digitalizar el negocio mediante el desarrollo de una plataforma web con dos perfiles de acceso, eliminando por completo el uso del papel y los errores humanos:

- **Para el propietario (Administrador):** Un sistema de gestión donde pueda cargar, actualizar y llevar el control exacto del stock de libros, indicando en tiempo real su disponibilidad y su estado físico. También un apartado de préstamos donde se vincula la salida de un libro con un usuario registrado. Incluirá fechas de retiro, fechas límite de devolución y un sistema de alertas (visuales o notificaciones) que avisa automáticamente cuando un cliente esté en demora, evitando la pérdida de los ejemplares. Módulo de Estadísticas, un panel visual que recopila automáticamente el historial de movimientos para mostrar qué libros o géneros son los más solicitados (top tendencias) y cuáles tienen menor rotación.

- **Para los clientes (Usuarios):** Un catálogo digital accesible desde cualquier dispositivo donde puedan verificar el stock disponible por su cuenta, realizar búsquedas filtradas (por nombre, autor o género) y recibir recomendaciones de lectura personalizadas basadas en el catálogo actual, agilizando la atención y modernizando la experiencia de compra o préstamo.

### Evaluación de Recursos

**Software:**
- Visual Studio Code (Entorno de desarrollo / Editor de código)
- HTML5, CSS3 y JavaScript (Lenguajes de programación del Frontend)
- Node.js (Entorno de ejecución del Backend)
- MySQL (Sistema de Gestión de Bases de Datos)
- Git y GitHub (Control de versiones y repositorio en la nube)

**Hardware:**
- Computadoras del equipo de desarrollo (Laptops o PC de escritorio)
- Dispositivo de gestión del propietario (PC de escritorio, laptop o tablet en la librería)
- Dispositivos de los clientes (Smartphones, tablets o computadoras personales)
- Servidor Web remoto / Infraestructura en la nube
- Conexión a Internet de banda ancha
