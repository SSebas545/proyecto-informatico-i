# Proyecto Informático I - Los Patismos

## Sistema de Gestión de Librería

### Descripción del Proyecto
Plataforma web para la digitalización de una librería tradicional (venta y préstamo de libros). El sistema cuenta con dos perfiles de acceso: Usuario/Comprador y Gerente/Administrador.
